# カーナビSD変換（Mac 用・無料）

Mac の音楽を、古いカーナビやカーオーディオで **曲名・アーティスト名・アルバム名がきちんと出る** MP3 にして、SD カードへ入れるアプリです。

## こんなときに

- Mac から SD カードに曲を入れたら、ナビで曲名が出ずファイル名になる
- 「保存できないファイルがあります」「音楽データがありません」で取り込みが止まる
- 1 フォルダに 99 曲入れたはずなのに取り込めない
- アーティスト名の書き方がバラバラで、同じ人が何人もいるように並ぶ

古い国産ナビの多くは、ID3 タグ Ver.1・JIS 形式しか読めない、1 フォルダ 99 曲まで（Mac が作る隠しファイルも数える）、「〜」などの記号や短い日本語のフォルダ名を読めない、といった決まりがあります。このアプリは機種に合わせて、これらを自動で避けます。

## できること

- 音楽フォルダからアーティストやアルバムを選んで、機種に合った MP3 に変換（音量もそろえられます）
- SD カードへ直接、または Mac のフォルダに書き出してから「SD カードへ送る」（Finder からドラッグでも可）
- SD カードがいっぱいになったら、次のカードに続きから入れる（アルバムは分けない）
- アーティスト名の書き方をまとめる
- 曲名の表記を CD・配信の正式な表記にそろえる（インターネットを使います。オフにもできます）
- 元の曲は読むだけで、書き換えません

## 動く環境

- macOS 13 以降（Intel / Apple Silicon）
- Apple の公証済み

## 対応機種

| 設定 | 向いている機器 |
|---|---|
| 汎用 MP3 | ほとんどのカーナビ・カーオーディオ・USB 対応機 |
| MP3 制限きつめ | 英数字のファイル名・短い名前・1 フォルダ 99 曲まで |
| MP3＋ジャケット画像 | 2012 年以降のナビ・ディスプレイオーディオ |
| AAC（m4a）＋ジャケット画像 | iPod 対応ナビ・新しめの機種 |
| Panasonic ストラーダ CN-HDS940D / 960D / 910D | **実機で確認済み** |

合わない機種は、タグの形式・文字コード・名前の長さ・1 フォルダの曲数などを変えた設定を自分で作れます。
実機で確かめたのは CN-HDS940D だけです。ほかの機種で動いた・動かなかったという報告は [Issues](https://github.com/Ryuuji-sakura/NaviSD/issues) で歓迎します。

## ライセンス・プライバシー

- 音声の変換に FFmpeg 7.1.1（LGPL v2.1 以降）と LAME 3.100（LGPL）を使っています。
- 「曲名の表記を自動で整える」をオンにしたときだけ、アーティスト名・アルバム名・曲名を Apple の検索サービス（iTunes Search API）に問い合わせます。それ以外に情報を送ることはありません。
- 無料・無保証です。個別のサポートはしていません。不具合の報告や「この機種で動いた」という情報は [Issues](https://github.com/Ryuuji-sakura/NaviSD/issues) へ。
